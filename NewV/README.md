# 🎾 AI Tennis Coach - مربی هوشمند تنیس

یک سیستم پیشرفته تحلیل ویدئوی تنیس با استفاده از هوش مصنوعی، بینایی ماشین و رابط کاربری مدرن PyQt6.

## ویژگی‌های کلیدی

- **تحلیل تکنیک با MediaPipe**: تشخیص نقاط کلیدی بدن و محاسبه زوایای مفاصل (آرنج، شانه)
- **تشخیص اشیاء با YOLOv8**: شناسایی خودکار بازیکن، راکت و توپ تنیس
- **مقایسه با حرفه‌ای‌ها**: امکان بارگذاری ویدئوی بازیکنان حرفه‌ای به عنوان الگو و مقایسه آماری
- **بازخورد هوشمند**: ارائه پیشنهادات اصلاحی مانند یک مربی واقعی بر اساس زوایا
- **داشبورد زنده**: نمایش لحظه‌ای آمار، زوایا و نمودار تغییرات
- **رابط کاربری مدرن**: تم تاریک (Dark Mode) با طراحی حرفه‌ای و روان

## پیش‌نیازها

برای اجرای این پروژه به کتابخانه‌های زیر نیاز دارید:

```bash
pip install opencv-python mediapipe ultralytics pyqt6 pyqtgraph numpy
```

> **نکته**: در اولین اجرا، مدل‌های YOLO و MediaPipe به صورت خودکار دانلود می‌شوند.

## نحوه اجرا

1. فایل `tennis_coach.py` را اجرا کنید:
   ```bash
   python tennis_coach.py
   ```

2. **بارگذاری ویدئوی خود**: دکمه "📂 بارگذاری ویدئوی من" را بزنید و ویدئوی تمرین خود را انتخاب کنید.

3. **(اختیاری) بارگذاری الگوی حرفه‌ای**: برای مقایسه دقیق‌تر، ویدئوی یک بازیکن حرفه‌ای را با دکمه "🏆 بارگذاری ویدئوی حرفه‌ای" لود کنید تا سیستم میانگین زوایای او را استخراج کند.

4. **شروع تحلیل**: دکمه "▶ شروع تحلیل" را بزنید. سیستم به صورت فریم‌به‌فریم ویدئو را پردازش کرده و بازخوردهای متنی و نموداری ارائه می‌دهد.

## ساختار کد

- `VideoAnalysisThread`: کلاس جداگانه برای پردازش سنگین ویدئو بدون فریز شدن رابط کاربری.
- `TennisCoachApp`: کلاس اصلی پنجره و مدیریت رویدادها.
- **منطق مربی**: توابعی برای محاسبه زاویه و مقایسه آن با استانداردها (مثلاً زاویه ایده‌آل آرنج بین ۹۰ تا ۱۱۰ درجه).

## توسعه آینده

- اضافه کردن تحلیل ضربات مختلف (فورهند، بک‌هند، سرویس)
- ذخیره گزارش تحلیل به صورت PDF
- پشتیبانی از دوربین آنلاین به جای فایل ویدئویی
